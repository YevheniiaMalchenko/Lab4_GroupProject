## Опис API

```c
struct ZScoreResult {
    double mean;       // Середнє арифметичне вибірки
    double stdDev;     // Стандартне вибіркове відхилення
    int status;        // 0: успіх; -1: помилка; -2: однакові значення (stdDev = 0)
};

struct IQRBounds {
    double q1;         // Перший квартиль (25%)
    double q3;         // Третій квартиль (75%)
    double iqr;        // Інтерквартильний розмах (q3 - q1)
    double lowerBound; // Нижня межа викидів (q1 - 1.5 * iqr)
    double upperBound; // Верхня межа викидів (q3 + 1.5 * iqr)
    int status;        // 0: успіх; -1: помилка
};

ZScoreResult zScore(const double* data, int n, double* outZScores);
IQRBounds iqrOutliers(const double* data, int n);
int detectOutliers(const double* data, int n, double threshold, int* outAnomalyFlags);
double anomalyRate(const double* data, int n, double threshold);
```

## Детальний опис функцій та Контракт

### 1. `zScore`
- **Призначення:** Розрахунок стандартизованих оцінок Z-Score для кожного елемента вибірки за формулою: $z_i = \frac{x_i - \bar{x}}{s}$, де $s$ — незміщене стандартне відхилення.
- **Параметри:**
  - `data` (`const double*`): вхідний масив числових значень.
  - `n` (`int`): кількість елементів у масиві. Повинно бути $n \ge 2$.
  - `outZScores` (`double*`): попередньо виділений буфер пам'яті розміру не менше $n$.
- **Повертає:** Структуру `ZScoreResult`.
  - Поле `status = 0`: обчислення успішні.
  - Поле `status = -1`: помилка (nullptr-вказівник або $n < 2$).
  - Поле `status = -2`: усі елементи у масиві ідентичні (дисперсія $0$), значення z заповнюються нулями.
- **Побічні ефекти:** Заповнює буфер `outZScores`.
- **Вимоги до пам'яті:** Пам'ять для `outZScores` виділяється та звільняється клієнтським додатком.

### 2. `iqrOutliers`
- **Призначення:** Визначення квартилів $Q_1$, $Q_3$, розмаху $IQR = Q_3 - Q_1$ та класичних меж Тьюкі для виявлення викидів: $[Q_1 - 1.5 \cdot IQR, Q_3 + 1.5 \cdot IQR]$.
- **Параметри:**
  - `data` (`const double*`): вхідний масив числових значень.
  - `n` (`int`): кількість елементів у масиві. Для коректного визначення 4 квартильних областей вимагається $n \ge 4$.
- **Повертає:** Структуру `IQRBounds`.
  - При некоректних даних (`data == nullptr` або $n < 4$) повертає `status = -1` та нульові значення.

### 3. `detectOutliers`
- **Призначення:** Бінарна класифікація елементів вибірки на нормальні та аномальні за критерієм Z-Score: $|z_i| > \text{threshold}$.
- **Параметри:**
  - `data` (`const double*`): вхідний масив чисел.
  - `n` (`int`): кількість елементів ($n \ge 2$).
  - `threshold` (`double`): поріг z-оцінки (зазвичай 2.0 або 3.0; вимагається $\text{threshold} > 0$).
  - `outAnomalyFlags` (`int*`): вихідний буфер розміру $n$ (значення: 0 — нормальне, 1 — викид/аномалія).
- **Повертає:**
  - Невід'ємне ціле число — кількість знайдених аномалій.
  - `-1` у разі некоректних аргументів (`nullptr`, $n < 2$, $\text{threshold} \le 0$).

### 4. `anomalyRate`
- **Призначення:** Розрахунок частки аномальних спостережень у вибірці: $\frac{\text{кількість аномалій}}{n}$.
- **Параметри:**
  - `data` (`const double*`): вхідний масив чисел.
  - `n` (`int`): кількість елементів ($n \ge 2$).
  - `threshold` (`double`): поріг z-оцінки ($\text{threshold} > 0$).
- **Повертає:**
  - Число від `0.0` до `1.0` — частка викидів.
  - `-1.0` при помилці валідації вхідних даних.

## Граничні випадки (Edge Cases) та Безпека
1. **Передача `nullptr` замість вказівників:** Бібліотека здійснює перевірку кожного вказівника на початку виклику, захищаючи процес від Access Violation.
2. **Недостатня кількість елементів ($n < 2$ або $n < 4$ для IQR):** Функції повертають визначений статус помилки без спроб виходу за межі масиву.
3. **Нульова дисперсія (усі $x_i$ однакові):** Усунено помилку ділення на нуль (Division by Zero); статус позначається як `-2`, а z-оцінки приймаються рівними `0.0`.
4. **Некоректний поріг ($\text{threshold} \le 0$):** Функції повертають код помилки `-1` або `-1.0`.
